🔑 Cấu Hình Khóa API

Nhập khóa API của bạn bên dưới. Hỗ trợ các dịch vụ như Gemini, OpenAI, DeepSeek...

📝 Cách lấy khóa API miễn phí (Gemini):

1. Truy cập Google AI Studio
2. Đăng nhập bằng tài khoản Google
3. Nhấn "Create API Key" → Tạo khóa mới
4. Sao chép khóa và dán vào ô trên
⚠️ Không chia sẻ khóa API cho người khác!
